Sobre o projeto

Esta página foi desenvolvida como um projeto de galeria de imagens responsiva.

O HTML foi utilizado para estruturar as telas, o CSS para definir a aparência e o JavaScript para adicionar funcionalidades e interações.

Também foi utilizado o framework Bulma para auxiliar na construção dos componentes e do layout.
